## 선택 기능인 AI 번역

AI 번역은 사용자가 글을 선택하고 번역을 요청할 때 실행됩니다. 앱은 선택한 글을 사용자의 컴퓨터에서 OpenAI의 HTTPS Responses API(`api.openai.com`)로 직접 전송합니다. 번역 대상 언어, 번역 지시문, 사용하는 모델 식별자(현재 `gpt-4.1-mini`)와 요청 설정도 함께 전송됩니다. 사용자의 OpenAI API 키는 OpenAI에 인증 정보로 전달됩니다. 네트워크 연결을 통해 IP 주소와 기술적 요청 정보도 서비스 제공자에게 전달될 수 있습니다.

이 요청에는 선택하지 않은 나머지 본문이나 다른 메모를 자동으로 첨부하지 않습니다. 번역 요청은 Dowon Park가 운영하는 서버를 경유하지 않습니다. 어떤 글을 전송할지는 사용자가 결정합니다. 다른 사람의 개인정보 등 공유할 권한이 없는 정보를 선택하지 않도록 주의해 주세요.

앱은 요청에 API 옵션 `store: false`를 지정하여 해당 요청의 응답 상태 저장을 비활성화합니다. **이 설정이 제공자의 모든 기록 미보관, 악용 감시 로그 미생성 또는 모든 정보의 즉시 삭제를 보장하지는 않습니다.** OpenAI가 수신한 정보에는 OpenAI의 처리·보관 정책, 계정 제어 기능과 적용되는 약관이 따릅니다. 번역을 사용하기 전에 [OpenAI API 데이터 제어 안내](https://platform.openai.com/docs/guides/your-data)와 [OpenAI 개인정보처리방침](https://openai.com/policies/privacy-policy/)을 확인해 주세요. 제공자는 사용자의 국가 외 다른 국가에서 정보를 처리할 수 있습니다.

번역 없이도 기본 메모 기능을 모두 사용할 수 있습니다. 추가 번역 요청을 하지 않거나 **AI 연결 설정 → 연결 해제**를 이용하면 해당 연결을 통한 이후 인증 요청을 중단할 수 있습니다. 번역 취소는 진행 중인 작업을 중단하려고 시도하지만 이미 OpenAI로 전송된 정보를 회수하지는 못합니다. 연결을 해제하거나 로컬 메모를 삭제해도 OpenAI가 별도로 보관하는 기록은 삭제되지 않습니다. 제공자 측 기록과 API 계정은 OpenAI에서 제공하는 제어 기능으로 관리해 주세요.

번역 결과 미리보기는 앱 메모리에 보관되며, 앱은 별도의 번역 이력을 디스크에 저장하지 않습니다. **선택 부분 바꾸기**를 누르면 결과가 메모의 일부로 저장되고, **복사**를 누르면 Windows 클립보드에 기록됩니다. 원문은 자동으로 바뀌지 않습니다. 일반적인 Windows 복사·붙여넣기도 사용할 수 있습니다. 클립보드 기록, 동기화와 다른 프로그램의 접근에는 Windows 및 해당 프로그램의 설정이 적용됩니다.

**연결 해제**는 앱 메모리에 있는 키와 저장된 키 파일을 지웁니다. 실행 중에만 사용하도록 변경하는 경우에도 이전에 저장한 키를 제거합니다. 이 동작은 OpenAI에서 API 키 자체를 폐기하는 기능은 아닙니다. 키의 폐기나 재발급은 OpenAI API 계정에서 진행해 주세요. 암호화가 손상되거나 잠금 해제된 Windows 계정에 대한 모든 접근으로부터 정보를 보호하는 것은 아닙니다.
