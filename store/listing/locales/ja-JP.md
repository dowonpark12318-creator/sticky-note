## Description

覚えておきたいことは目の前に。スペースが必要なら、小さく折りたたんで。Corner Noteは、アイデアや予定、手元に置いておきたい文章を書ける無料のデスクトップ付箋アプリです。

+で付箋を追加し、色を選び、辺をドラッグしてサイズを調整できます。付箋は自由に重ねて配置できます。タイトルをクリックすると名前を変更でき、本文をスクロールした状態でもタイトルバーをドラッグして移動できます。「常に最前面」は付箋ごとに設定でき、ほかの付箋の設定には影響しません。オフの付箋はタスクバーやAlt+Tabで切り替えられます。

角を対角線の3分の1だけ引くと、その方向の画面の隅に折りたたまれます。折りたたんだ付箋も好きな場所へ移動できます。本体をダブルクリックすると最初の隅に戻り、斜めのつまみを内側へ引くと元に戻ります。内容とウィンドウの状態はコンピューターに自動保存されます。−はトレイに隠し、×は確認してからその付箋を削除します。

任意のAI翻訳には、リアルタイムの生成AIサービスを使用します。文章を選択して言語を指定し、結果を確認してコピーするか、選択部分を自分で置き換えます。OpenAIへ送信されるのは選択した文章だけで、原文は自動で上書きされません。翻訳にはインターネット接続と本人のOpenAI APIキーが必要です。OpenAI API利用料金はChatGPTのサブスクリプションとは別です。アプリ自体は無料で、基本的な記入と保存はアカウントやAPIキーなしでオフラインでも使えます。

メニュー、ヘルプ、5段階のチュートリアルはコンピューターの優先言語に合わせて表示されます。オフラインガイドも付属しています。韓国語、英語、日本語、中国語簡体字・繁体字、スペイン語、フランス語、ドイツ語、ポルトガル語、イタリア語に対応し、その他の表示言語は英語になります。書いた文章は自動翻訳しません。

Windows 10バージョン2004（ビルド19041）以降およびWindows 11のx64環境向けです。問題や不適切なAI結果はdowonpark12318@gmail.comへご連絡ください。APIキーや機密情報は送らないでください。

## Product features

- 文章・色・サイズ・位置を個別に保存する複数の付箋と自由な重ね合わせ
- 付箋ごとに最前面表示を設定し、オフの付箋はAlt+Tabで切り替え
- タイトルをクリックして名前を変更し、本文のスクロール中も付箋を移動
- 角を対角線の3分の1だけ引いて画面の隅に折りたたむ
- 折りたたんだ付箋を自由に移動し、ダブルクリックで最初の隅へ戻す
- ローカル自動保存、トレイへの非表示、確認後の削除
- 選択した文章のAI翻訳と、結果の確認・コピー・手動での置き換え
- 10種類の表示言語の自動選択と5段階のチュートリアル
