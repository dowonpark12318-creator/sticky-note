## Description

기억할 일은 눈앞에 두고, 공간이 필요하면 작게 접어 두세요. Corner Note는 아이디어와 할 일, 가까이 두고 싶은 짧은 글을 적는 무료 데스크톱 메모 앱입니다.

+로 여러 메모를 만들고, 색을 고르고, 변 테두리를 끌어 크기를 조절하세요. 메모는 자유롭게 겹쳐 놓을 수 있습니다. 메모 제목을 클릭해 이름을 바꾸고, 본문을 아래로 스크롤한 상태에서도 제목 표시줄을 끌어 이동할 수 있습니다. ‘항상 위’는 메모마다 따로 선택하며 다른 메모의 설정은 바뀌지 않습니다. 끈 메모는 작업 표시줄과 Alt+Tab으로 전환할 수 있습니다.

모서리를 대각선 거리의 1/3만 끌면 그쪽 화면 구석에 접힙니다. 접힌 메모도 원하는 곳으로 옮길 수 있어요. 몸체를 두 번 클릭하면 처음 접힌 구석으로 돌아가고, 대각선 손잡이를 안쪽으로 당기면 펼쳐집니다. 메모 내용과 창 상태는 컴퓨터에 자동 저장됩니다. −는 트레이로 숨기고, ×는 확인 후 해당 메모를 삭제합니다.

선택 기능인 AI 번역은 실시간 생성형 AI 서비스를 사용합니다. 번역할 글을 선택하고 언어를 고른 뒤, 결과를 확인해 복사하거나 선택 부분을 직접 바꿀 수 있습니다. 선택한 글만 OpenAI로 전송되며 원문을 자동으로 덮어쓰지 않습니다. 번역에는 인터넷과 본인의 OpenAI API 키가 필요합니다. OpenAI API 사용료는 ChatGPT 구독과 별도로 청구됩니다. 메모 앱 자체는 무료이며, 기본 작성과 저장은 계정이나 API 키 없이 오프라인에서도 사용할 수 있습니다.

메뉴·도움말·5단계 튜토리얼은 컴퓨터 기본 언어에 맞춰 표시됩니다. 오프라인 설명서도 포함되어 있습니다. 한국어, 영어, 일본어, 중국어 간체·번체, 스페인어, 프랑스어, 독일어, 포르투갈어, 이탈리아어를 지원하며 다른 표시 언어는 영어로 대체합니다. 작성한 메모는 자동 번역하지 않습니다.

Windows 10 버전 2004(빌드 19041) 이상 및 Windows 11 x64용입니다. 문제나 부적절한 AI 결과는 dowonpark12318@gmail.com으로 알려 주세요. 신고에 API 키나 민감한 글을 포함하지 마세요.

## Product features

- 글·색상·크기·위치를 따로 저장하는 여러 메모와 자유로운 겹침 배치
- 메모마다 독립적인 항상 위 설정과 끈 메모의 Alt+Tab 전환
- 제목을 클릭해 이름 변경, 본문 스크롤 상태에서도 펼친 메모 이동
- 모서리를 대각선 거리의 1/3만 끌어 화면 구석으로 접기
- 접힌 메모의 자유로운 이동과 더블클릭으로 처음 구석 복귀
- 컴퓨터에 자동 저장, 트레이 숨김, 확인 후 메모 삭제
- 선택한 글의 AI 번역과 결과 미리보기·복사·직접 바꾸기
- 10개 표시 언어 자동 선택과 5단계 기능 튜토리얼
