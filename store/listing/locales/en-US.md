## Description

Keep a reminder in view, then fold it away when you need more room. Corner Note is a free desktop note app for ideas, tasks and small pieces of text you want nearby.

Create several notes with +, choose their colors, resize them by dragging an edge, and arrange them freely—even overlapping. The note you last click or edit comes to the front. Turn Always on top on for all notes, or turn it off to switch with the taskbar and Alt+Tab normally.

Drag a corner one third of the way across the note’s diagonal to fold it into the matching screen corner. Move the folded note wherever you like. Double-click its body to return it to the original corner, or pull the diagonal grip inward to unfold it. Each note saves its content and window state on your computer. The − button hides a note to the tray; × asks for confirmation before deleting it.

Optional AI translation uses a live generative AI service. Select text, choose a target language, and review the result before copying it or replacing the selection. Only selected text is sent to OpenAI; your original note is never replaced automatically. Translation requires internet access and your own OpenAI API key. OpenAI API usage is billed separately from a ChatGPT subscription. The note app itself is free, and basic writing and saving work offline without an account or API key.

Menus, help and the five-step tutorial follow your computer’s preferred language. An offline user guide is also included. Display languages: Korean, English, Japanese, Simplified and Traditional Chinese, Spanish, French, German, Portuguese and Italian. Other display languages fall back to English. Your written notes are not translated automatically.

For Windows 10 version 2004 (build 19041) or later and Windows 11, x64. To report a problem or an inappropriate AI result, contact dowonpark12318@gmail.com. Do not include API keys or sensitive text in your report.
