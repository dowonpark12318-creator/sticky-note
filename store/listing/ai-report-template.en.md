# Report an AI result in Corner Note

Send to: [dowonpark12318@gmail.com](mailto:dowonpark12318@gmail.com)  
Suggested subject: **Corner Note AI report**

Use this form for an incorrect, harmful, or inappropriate translation. You do not need to publish your note or explain the issue in a public GitHub post. Email is an available reporting route; the app does not automatically send a report.

Copy the fields below into your email and fill in only what is needed:

```text
App version:
Windows version:
Interface language:
Source and target language:
Type of problem:
What happened:
What you expected:
Approximate time of the request (optional; include your time zone):
Short redacted example of input/output (optional):
Steps to reproduce (optional):
```

Do not include an API key, password, payment information, an entire private note, or another person's personal information. A report can begin with a description and no text excerpt. Crop or redact screenshots before attaching them. Share only information you have permission to disclose.

AI results should be reviewed before use. You can leave the original note unchanged by not choosing **Replace selection**, and you can stop future requests through **AI translation settings → Disconnect**. If your API key was exposed, revoke it in your OpenAI account; deleting it from the app does not revoke the provider's key.

Support email is handled as described in the [Privacy Policy](privacy/privacy-policy.en.md). The developer will review reports to investigate and take appropriate action, but this template does not promise a particular result or response deadline. It is not an emergency service.
