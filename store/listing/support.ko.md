## 실행과 업데이트

Windows 10 버전 2004(빌드 19041) 이상 또는 Windows 11의 x64 PC를 사용해 주세요. 이 배포본은 Windows 데스크톱용이며 네이티브 x86·ARM64·Xbox 패키지는 제공하지 않습니다.

포터블 ZIP은 **모든 파일을 압축 해제**한 뒤 `CornerNote.exe`를 실행합니다. 실행 파일만 다른 곳으로 옮기지 마세요. 이전 버전을 업데이트할 때는 트레이 아이콘을 오른쪽 클릭해 **종료**한 뒤, 새 ZIP을 새 폴더에 풀어 실행합니다. **−**는 메모를 숨길 뿐 앱을 종료하지 않습니다.

제출 자료로 제공되는 `CornerNote-Store-x64.msix`는 **서명 전 Partner Center 제출용 패키지**입니다. 일반적인 더블클릭 설치 파일이 아니며, Microsoft가 심사 후 Store 배포용으로 서명합니다. `Development` MSIX는 별도의 검증용 빌드로 Store 제출용이 아닙니다. 서명되지 않은 제출·개발 파일을 받은 경우 일반 실행 테스트는 포터블 ZIP을 사용해 주세요. 설치 경고를 우회하기 위해 출처가 불분명한 인증서를 등록하지 마세요.

## 기본 조작

- **?**에서 도움말과 다섯 단계 기능 둘러보기 다시 보기를 열 수 있습니다.
- **+**는 새 빈 메모를 만듭니다. 메모는 겹쳐 놓을 수 있고 가장 최근에 클릭하거나 편집한 메모가 위로 올라옵니다.
- **−**는 해당 메모만 숨깁니다. 트레이 메뉴에서 메모를 다시 열거나 모두 표시하거나 새로 만들 수 있습니다. 트레이 아이콘이 Windows의 숨겨진 아이콘 영역에 있을 수도 있습니다.
- **×**는 해당 메모를 삭제할지 묻습니다. **아니요**는 취소하고 **네**는 해당 메모와 저장된 글을 삭제합니다. 실행 취소 기능은 없습니다.

- 접힌 메모의 몸체를 끌면 자유롭게 옮길 수 있습니다. 몸체를 두 번 클릭하면 처음 접힌 위치로 돌아갑니다. 대각선 손잡이를 안쪽으로 끌거나 손잡이를 선택한 뒤 Enter를 누르면 펼쳐집니다.

## 항상 위를 켰는데 Alt+Tab에 보이지 않아요

**항상 위** 설정은 모든 메모에 함께 적용됩니다. 켜면 일반 앱 창 위에 표시되고 작업 표시줄에서 제외됩니다. 끄면 작업 표시줄과 Alt+Tab으로 일반 창처럼 전환할 수 있습니다. Windows 보안·잠금 화면, 일부 독점 전체 화면 앱, 모든 다른 최상위 창보다 항상 위에 보이는 것은 보장하지 않습니다.

## 메모가 사라졌어요

먼저 트레이 메뉴를 확인해 주세요. 메모가 삭제된 것이 아니라 숨겨졌을 수 있습니다. 앱을 종료했다 다시 열면 저장 파일에 남아 있는 메모가 복원됩니다. 마지막 메모까지 삭제하면 다시 실행하거나 트레이를 사용할 때 새 빈 메모가 생성될 수 있지만, 삭제한 메모를 되살리는 실행 취소 기능은 아닙니다.

포터블 버전은 일반적으로 `%APPDATA%\Corner Note\note-state.json`에 저장합니다. 메모는 읽을 수 있는 텍스트 파일이므로 Windows 계정과 백업을 보호해 주세요. Store/MSIX 데이터 위치와 제거 방식은 Windows 패키지 규칙을 따릅니다. **기존 포터블 메모나 기억한 키가 MSIX 설치판으로 자동 이전된다고 가정하지 마세요.** 설치 유형 변경, 앱 초기화 또는 데이터 삭제 전에 원래 데이터를 백업해야 합니다. 문제를 조사하는 동안 출처를 모르는 저장 파일을 덮어쓰지 마세요.

번역할 본문으로 전송되는 것은 선택한 글이며 한 번에 최대 6,000자까지 요청할 수 있습니다. 실시간 생성형 AI를 이용하므로 결과가 틀리거나 부적절할 수 있습니다. 복사하거나 적용하기 전에 직접 확인해 주세요. **선택 부분 바꾸기**는 별도로 눌러야 하며 원문이 자동으로 바뀌지 않습니다. 요청 도중 메모를 수정했다면 결과를 복사해 사용해 주세요.

요청이 실패하면 인터넷 연결, API 키 권한, API 사용 한도와 잔액을 확인해 주세요. ChatGPT 구독만으로 OpenAI API 크레딧이 제공되는 것은 아닙니다. **연결 해제**는 앱의 현재 키와 기억한 키를 지웁니다. 키 자체를 폐기하거나 바꾸려면 OpenAI 계정에서 별도로 처리해야 합니다. 지원 이메일로 키를 보내지 마세요.
