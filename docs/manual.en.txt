Corner Note
Version 1.5.0

GETTING STARTED
1. Extract the entire ZIP to a new folder and run CornerNote.exe. Keep the executable and other files together.
2. Windows 10/11 64-bit is required. No account or Node.js installation is needed for taking notes.
3. Before updating, right-click the tray icon and choose Quit. The minus button only hides a note; it does not quit the app.
4. The app follows your Windows preferred language. It supports Korean, English, Japanese, Simplified and Traditional Chinese, Spanish, French, German, Portuguese, and Italian. Other display languages fall back to English. Your note text is never translated automatically.

WRITING AND ARRANGING NOTES
- The titlebar buttons are Help (?), New note (+), Hide (-), and Delete (x).
- Click + to open another blank note. Notes may overlap. The last note you click or edit comes to the front.
- Each note saves its text, color, size, position, and folded state automatically on your computer.
- Drag the titlebar to move an unfolded note. Drag any of the four edges to resize it. Corners are used for folding.
- Drag a corner toward the opposite corner by at least one third of the diagonal and release. The note folds into that corner of the screen.
- Release sooner or press Escape while dragging to cancel folding.
- Drag the body of a folded note to move it anywhere. Double-click its body to return it to the original folded corner without unfolding it.
- Pull the small diagonal grip inward, or focus it and press Enter, to unfold.
- Always on top applies to every note. When enabled, notes stay above other apps and are excluded from the taskbar. When disabled, use the taskbar or Alt+Tab to switch to them normally.
- Click - to hide only that note. The tray menu lets you show individual notes, show all notes, or create a new one. Look in the taskbar's hidden icon area if necessary.
- Click x to ask whether to delete the current note. No cancels; Yes deletes that note and its saved text. Other notes are kept. Deleted notes do not return after restarting.
- After the last note is deleted, the tray can open a new blank note. Restarting the app also creates a new blank note.
- Choose Quit from the tray menu to close the app. Remaining notes and their window states return next time.

FIRST-RUN GUIDE
The five-step guide introduces moving, resizing, folding/unfolding, moving folded notes, and AI translation. Finish or skip it. To replay it, open Help (?) and select Take the tour again.

TRANSLATING SELECTED TEXT
Basic notes work offline without an API key. AI translation requires internet access and your own OpenAI API key. Write some text, select it, click Translate, and open AI translation settings in the language menu to connect it. OpenAI API usage is billed separately from a ChatGPT subscription.

1. Write some text. A Translate button appears in the center of the bottom toolbar.
2. Drag to select the text you want to translate, click Translate, then choose a target language. The initial targets are your computer's actual language and English, without duplicates.
3. Use Add to search for additional language names or codes. Added languages are shared between notes and remembered.
4. While a request is running, a spinner is shown. You can cancel the translation.
5. Review the result, then Copy it or explicitly choose Replace selection. The original is never replaced automatically. If you edited the note during translation, copy the result instead.

Only the selected text is sent to OpenAI, up to 6,000 characters per request.

API KEY AND DATA
The API connection, target-language list, guide completion, and always-on-top setting are shared between notes. Your API key is used only for the current session unless you explicitly choose Remember key on this computer. Remembered keys are encrypted using Electron safeStorage on Windows and stored separately from notes. If secure storage is unavailable, use the key for the current session only. Disconnect clears both the current and remembered key.

Notes and shared preferences are stored in note-state.json in the app's user data directory. The portable app normally uses %APPDATA%\Corner Note. A remembered encrypted key is in translation-key.json. Basic notes are not sent to a server. Deleting the portable program folder does not delete the saved notes. Store MSIX uses Windows package data rules; existing portable data migration must be checked before public release.

WINDOWS AND BUILD INFORMATION
The portable ZIP is an unsigned test build and may show Windows SmartScreen warnings. It does not request administrator privileges. Windows secure desktops, some exclusive full-screen apps, and other topmost windows may appear above notes.

A Development MSIX is an unsigned build for validation, not a Microsoft Store release or a normal double-click installer. The Store build uses Partner Center package identity DowonPark.CornerNote, publisher Dowon Park. Microsoft signs the MSIX after certification; a local development installation requires a separately trusted test certificate.
