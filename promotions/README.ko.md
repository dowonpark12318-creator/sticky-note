# CornerNote Instagram 홍보 영상

최신 수정본: [항상 위 기능을 추가한 26초 영상](always-on-top/CornerNote-Instagram-AlwaysOnTop.mp4). 실제 버튼을 끄고 켜서 다른 창 뒤로 가려지는 모습과 다른 창을 작업해도 앞에 유지되는 모습을 비교합니다. [제작 정보](always-on-top/README.ko.md)

아래는 기존 20초 영상의 정보입니다.

- 파일: `CornerNote-Instagram.mp4`
- 세로 1080×1920, 30fps, 20초, H.264/yuv420p, MP4 faststart
- 소리 없음
- 자막: Nanum Pen Script 손글씨체, 46px, 채도가 낮은 갈색, 배경 상자/윤곽선 없음
- 마지막 4초: `available in microsoft store`

실제 CornerNote v1.6.0 Electron 앱을 별도의 Linux X11 화면에서 조작하여 녹화했습니다. Windows 바탕화면 녹화가 아닙니다. 메모 UI를 합성하지 않았으며, 720×1280 원본 화면을 세로1080×1920으로 확대하고 자막만 추가했습니다.

실제 동작: 글 작성 → +로 메모 추가 → 크기 조절 → 모서리 접기 → 접힌 메모 이동 → 다시 펼치기. AI 키, 실제 개인정보, 외부AI요청은 사용하지 않았습니다.

자막 글꼴: Google Fonts Nanum Pen Script (SIL Open Font License 1.1). 원본 파일과 재현용 녹화/인코딩 자료는 작업 폴더에 있습니다.
