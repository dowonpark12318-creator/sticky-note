# 모서리 메모 · Corner Note

Windows용 메모 앱입니다. 여러 메모를 겹쳐 놓고, 마지막으로 클릭하거나 편집한 메모를 위로 올릴 수 있습니다. 다른 창 위에 고정하거나 일반 창처럼 전환할 수 있고, 종이 모서리를 대각선으로 끌면 화면 구석에 접어 둘 수 있습니다. v1.5.0은 Windows 기본 설정 언어에 따라 한국어·영어·일본어·중국어 간체/번체·스페인어·프랑스어·독일어·포르투갈어·이탈리아어 UI를 자동 선택하며 MSIX 빌드를 추가했습니다. 다른 표시 언어는 영어로 대체합니다. 작성한 글은 자동 번역하지 않습니다.

## Windows에서 사용하기

테스트 실행 파일은 [다운로드 페이지](https://github.com/dowonpark12318-creator/sticky-note/releases)의 최신 **모서리 메모 Windows 테스트** → **Assets** → **CornerNote-Windows-x64.zip**에서 로그인 없이 받을 수 있습니다. 자세한 다운로드 절차와 직접 확인할 항목은 [Windows 테스트 가이드](WINDOWS-테스트.md)를 참고하세요.

`dist/CornerNote-Windows-x64.zip`을 **모두 압축 해제**하고 폴더 안의 `CornerNote.exe`를 실행하세요. Windows 10/11 x64용 포터블 앱입니다. 설치와 계정이 필요하지 않습니다. 실행 파일과 나머지 파일을 같은 폴더에 보관하세요.

업데이트할 때는 **이전 버전을 트레이 메뉴의 `종료`로 완전히 닫고**, 새 ZIP을 **새 폴더에 모두 압축 해제**한 뒤 그 안의 `CornerNote.exe`를 실행하세요. 기존 메모는 앱 데이터 폴더에 남아 새 버전에서 이어집니다.

- 제목 표시줄의 `?`와 `−` 사이에 있는 `+`를 누르면 현재 메모 근처에 빈 메모가 하나 더 열립니다. 여러 메모를 자유롭게 겹쳐 놓을 수 있습니다.
- 겹친 메모는 마지막으로 클릭하거나 편집한 것이 다른 메모 위로 올라옵니다. 다른 메모의 위치나 크기를 자동으로 바꾸지 않습니다.
- 메모별 글·색상·크기·접힌 상태·위치는 각각 컴퓨터에 자동 저장됩니다.
- 윗부분을 잡고 창을 이동할 수 있습니다.
- 네 변의 테두리에 마우스를 올린 뒤 끌면 메모 크기를 조절합니다. 모서리는 접기 동작으로 사용합니다.
- 네 모서리 중 하나를 잡고 반대편 방향으로 대각선 거리의 **1/3 이상** 끈 뒤 놓으면, 도착 방향의 화면 모서리에 접혀 붙습니다.
- 접힌 메모는 처음에는 화면 구석에 붙고, 이후 몸체를 끌어 원하는 위치로 이동할 수 있습니다.
- 옮긴 접힌 메모의 몸체를 두 번 클릭하면 처음 접혔던 위치로 돌아옵니다. 이때 메모는 계속 접힌 상태이며, 처음 위치도 재실행 후 유지됩니다.
- 접힌 메모의 대각선 가장자리에 있는 작은 손잡이를 화면 안쪽으로 당기거나, 키보드로 선택 후 Enter를 누르면 펼쳐집니다.
- `항상 위`는 **모든 메모에 함께 적용**됩니다. 켜면 다른 앱 위에 고정되고 작업 표시줄에서 제외됩니다. 끄면 일반 창처럼 작업 표시줄과 Alt+Tab으로 전환할 수 있고 다른 앱 뒤에 가려질 수 있습니다. 두 모드 모두 마지막으로 선택한 메모가 다른 메모 위로 올라옵니다.
- 대각선 거리의 1/3 미만에서 놓거나 드래그 도중 Escape를 누르면 접기가 취소됩니다.
- 제목 표시줄은 `? + − ×` 순서입니다. `×`를 누르면 `정말 메모를 삭제할까요?`가 표시됩니다. `아니요`는 취소하고, `네`는 해당 메모와 저장된 내용을 삭제합니다. 다른 메모는 유지됩니다. 마지막 메모를 삭제해도 트레이에서 새 메모를 만들 수 있으며, 다음 실행에는 새 빈 메모가 열립니다.
- `−`는 현재 메모만 트레이로 숨깁니다. 트레이 메뉴에서 각 메모를 다시 열거나, 모두 표시하거나, 새 메모를 만들 수 있습니다. `종료`는 앱의 모든 메모 창을 닫습니다.

`항상 위`는 처음 실행할 때 켜져 있습니다. 종료 후 다시 실행해도 모든 메모의 내용과 창 상태가 유지됩니다. 메모가 겹쳐 있어도 자동 정렬하지 않으며, 접기를 완료하는 순간에만 해당 방향의 화면 구석에 붙습니다. 이후에는 접힌 메모도 원하는 위치로 옮길 수 있습니다. 다른 앱으로 전환할 때 입력 포커스를 빼앗지 않습니다. Windows 보안 화면(UAC·잠금 화면), 일부 독점 전체 화면 앱, 다른 최상위 창보다 위에 표시되는 것은 보장하지 않습니다.

처음 실행하면 이동, 크기 조절, 접기·펼치기, 접힌 메모 이동, AI 번역을 소개하는 **다섯 단계 안내**가 나옵니다. 완료하거나 건너뛸 수 있고, 나중에 `?` 도움말의 `기능 둘러보기 다시 보기`에서 다시 열 수 있습니다.

## 표시 언어와 MSIX

메뉴·도움말·튜토리얼·번역 화면·날짜·글자 수와 트레이는 Windows의 기본 설정 언어를 따릅니다. 10개 표시 언어를 지원하며 다른 언어는 영어로 표시합니다. 번역 대상 목록의 첫 언어는 지원 UI 언어와 관계없이 컴퓨터의 실제 기본 언어를 유지합니다. 압축 해제한 `Help/manual.html`은 브라우저 기본 언어에 맞춰 설명서를 표시합니다.

Windows SDK로 `npm run pack:msix:dev`를 실행하면 테스트용 식별정보를 가진 서명되지 않은 MSIX를 만듭니다. Store 제출용 `npm run pack:msix`는 `msix/identity.json`의 실제 Partner Center 식별정보를 사용합니다. 설치 검사에서는 임시 복사본에만 서명하고 검사 후 앱·인증서·키를 지웁니다. 절차와 제한은 [MSIX 빌드 안내](store/MSIX.md)에 있습니다.

## 선택한 글 번역하기

메모 작성과 저장은 인터넷이나 API 키 없이 사용할 수 있습니다. AI 번역은 인터넷 연결과 **본인의 OpenAI API 키**가 필요합니다. 앱의 `?` 도움말 → `AI 연결 설정`에서 키를 입력하세요. 키가 없는 상태에서 처음 번역하면 연결 안내가 열립니다. **OpenAI API 사용료는 ChatGPT 구독과 별도로 본인 API 계정에 청구됩니다.**

1. 메모에 글을 입력하고 번역할 부분을 드래그해 선택합니다. 글이 있으면 아래 도구 모음 가운데에 `번역` 버튼이 나타납니다.
2. `번역`을 누르고 언어를 선택합니다. 기본 목록은 **PC의 언어 설정을 지역·문자 체계까지 유지한 언어와 영어**입니다. PC 언어가 영어라면 중복으로 표시하지 않습니다.
3. 다른 언어는 `추가`에서 이름이나 언어 코드로 찾아 넣습니다. 추가한 목록은 재실행해도 유지됩니다.
4. 요청 중에는 회전 표시가 나타나며 취소할 수 있습니다. 결과는 먼저 미리보기로 표시됩니다.
5. `복사`로 가져오거나 `선택 부분 바꾸기`를 눌러 직접 적용합니다. 원문은 자동으로 바뀌지 않습니다. 번역 중 메모를 수정했다면 바꾸기 대신 복사를 사용합니다.

번역을 요청하면 **선택한 글만 OpenAI로 전송**됩니다. 한 번에 최대 6,000자까지 선택할 수 있습니다. 메모 전체를 자동으로 전송하지 않습니다.

번역 언어 목록, 안내 완료 여부, AI 연결은 모든 메모가 공유합니다. API 키는 기본적으로 이번 앱 실행에서만 사용하며 종료하면 지워집니다. `이 컴퓨터에서 키 기억하기`를 선택하면 Windows에서 Electron `safeStorage`로 암호화해 별도 파일에 보관합니다. 안전한 저장을 사용할 수 없는 환경에서는 실행 중에만 사용할 수 있습니다. 키는 메모 저장 파일인 `note-state.json`에 넣지 않습니다. `AI 연결 설정`의 `연결 해제`는 실행 중인 키와 기억해 둔 키를 지웁니다.

## Windows 실행 경고와 권한

이 포터블 배포본은 코드 서명되지 않아 Windows SmartScreen 경고가 표시될 수 있습니다. 이 경고는 Windows가 다운로드 파일의 신뢰도와 평판을 판단해 표시하므로 앱 안에서 관리자 승인창으로 바꿀 수 없습니다. 앱은 관리자 권한을 요청하지 않습니다. UAC 승인창을 띄우도록 바꾸면 실제 관리자 권한을 요구하게 되며 SmartScreen 경고를 해결하지 않습니다.

경고를 줄이려면 신원이 검증된 인증서로 코드 서명하고 배포 평판을 쌓는 과정이 필요합니다. 서명한 새 파일도 처음에는 경고가 나올 수 있고, 자체 서명만으로는 공개 배포의 신뢰가 생기지 않습니다. Microsoft Store의 MSIX 배포도 별도의 선택지입니다. 자세한 기준은 Microsoft의 [SmartScreen 평판 안내](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation), [코드 서명 선택지](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/code-signing-options), [UAC와 관리자 권한 안내](https://learn.microsoft.com/en-us/cpp/security/how-user-account-control-uac-affects-your-application)를 참고하세요. 실제 PC의 창 표시 순서와 Alt+Tab 동작은 Windows에서 수동으로 확인합니다.

## 개발

Node.js 22.12 이상과 npm이 필요합니다. 기존 체크아웃에서 실행합니다.

```sh
npm ci
npm run setup
npm start
```

```sh
npm test             # 메모 이전·표시 순서·좌표·접기·번역 요청·키 보관 단위 테스트
npm run test:ui      # 메모 저장·입력·색상·접기/펼치기 브라우저 테스트
npm run test:features # 모의 AI 응답으로 번역·언어 목록·첫 실행 안내 테스트
npm run test:locales # 한국어·영어 자동 선택과 메뉴·튜토리얼 검사
npm run test:desktop # 실제 Electron 여러 창·IPC·저장·복원 테스트 (그래픽 화면 필요)
npm run pack:win     # Windows x64 실행 폴더 + ZIP + SHA-256
npm run pack:msix:dev # Windows SDK: 개발용 unsigned MSIX (pack:win 후)
```

브라우저 테스트는 기본적으로 설치된 Chromium 또는 Playwright Chromium을 사용합니다. 필요하면 `npx playwright install chromium`을 실행하거나 `CHROMIUM_PATH`로 브라우저 경로를 지정하세요. Linux에서 데스크톱 테스트에는 X11 그래픽 화면이 필요합니다. 앱 코드는 Electron 샌드박스를 유지합니다.

이 클라우드 Linux는 Chromium의 OS 샌드박스를 지원하지 않으므로 데스크톱 테스트에만 `ELECTRON_TEST_NO_SANDBOX=1 npm run test:desktop`을 사용했습니다. 기본 앱과 Windows 패키지의 샌드박스 설정은 유지합니다. Windows CI는 샌드박스를 켠 데스크톱 테스트를 실행하며, 이 테스트가 통과한 경우에만 Release를 게시합니다.

Windows 패키지는 Linux에서도 만들 수 있습니다. 생성된 파일은 `dist/` 아래에 있으며 Git에 포함하지 않습니다. Windows CI는 `npm test`, 모의 응답을 사용하는 `npm run test:features`, 실제 Electron 데스크톱 테스트를 실행합니다. 실제 OpenAI API 호출은 API 키를 제공받지 않아 검증하지 않았습니다. 실제 응답·청구·Windows 화면 전환 확인 절차는 [Windows 테스트 가이드](WINDOWS-테스트.md)에 있습니다. Windows 실행 검증·서명·배포는 별도 단계입니다.

## 구조와 데이터

`electron/`은 창·트레이·파일 저장과 AI 요청을, `renderer/`는 메모와 접기 제스처를 담당합니다. 렌더러에는 Node.js 권한이 없으며 제한된 IPC만 노출합니다. 기본 메모 기능에는 외부 서버·로그인·API 키가 필요하지 않습니다.

모든 메모와 공통 설정은 `%APPDATA%\Corner Note\note-state.json`에 저장됩니다. 파일 형식 버전 2의 `notes` 배열에 메모별 글·색상·크기·접힌 상태·현재 위치와 처음 접힌 위치를 보관하고, `항상 위`, 번역 언어 목록과 안내 완료 여부는 공통 설정으로 저장합니다. 기존 단일 메모 형식은 처음 읽을 때 자동으로 새 형식으로 옮기므로 메모를 따로 복사할 필요가 없습니다. 저장은 임시 파일을 쓴 뒤 원자적으로 교체하며 종료 시 대기 중인 저장을 마칩니다. 손상된 파일은 `.corrupt-...` 이름으로 보존합니다. 기억하도록 선택한 API 키는 같은 사용자 데이터 폴더의 `translation-key.json`에 암호화해 따로 보관합니다. 앱 폴더를 지워도 사용자 데이터 폴더의 메모는 남습니다. 브라우저에서 UI를 열면 개발·테스트용 localStorage를 사용하고, 데스크톱 메모 파일과는 별개입니다. 여러 메모 생성과 실제 AI 연결은 데스크톱 앱에서 사용합니다.
